== Data Classification and Encoding Guide

This annex renders the data classification and encoding guide directly
from the S-100 Feature Catalogue instance document
(`FC/102_3_0_0_FC.XML`) against the published S-100 Feature Catalogue
schema (`FC/schema/S100FC.xsd`). The catalogue file is the source of
record; the guidance content the catalogue does not carry (primitive,
constraint, unit, resolution, remarks) is maintained inline below.
